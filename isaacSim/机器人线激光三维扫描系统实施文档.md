# 基于法奥协作机械臂的单线激光三维扫描与点云重建实施文档

> 适用系统：Ubuntu 22.04台式机 + 法奥协作机械臂 + 海康GigE工业相机 + 6 mm镜头 + 450 nm/150 mW线激光
> 目标：先完成V形坡口焊前线扫建图，再升级到焊后、随焊后视和多层多道逐道几何闭环。

---

## 1. 总体原理

线激光每一帧提供一个三维横截面，机械臂沿焊缝方向移动提供第三维位置。连续截面根据机器人位姿和手眼标定关系转换到统一坐标系，形成完整点云。

```text
激光条纹图像
→ 去畸变
→ 亚像素条纹中心
→ 像素射线与激光平面求交
→ 相机坐标系单帧轮廓
→ 获取对应时刻机器人位姿
→ 手眼坐标变换
→ 基坐标系/工件坐标系
→ 多帧累计
→ 点云滤波、坡口识别和轨迹生成
```

推荐分两阶段：

1. **几何验证阶段**：激光常亮、相机连续采集、机器人低速移动。
2. **正式同步阶段**：ESP32-S3硬触发相机，相机Strobe门控激光TTL，曝光时刻插值机器人位姿。

## 5. 相机内参与镜头畸变标定

### 5.1 求解参数

\[
K=
\begin{bmatrix}
f_x&0&c_x\\
0&f_y&c_y\\
0&0&1
\end{bmatrix}
\]

标准畸变模型：

\[
D=[k_1,k_2,p_1,p_2,k_3]
\]

### 5.2 图像采集

建议拍50～60张，最终保留25～35张高质量图像。标定板应覆盖：

- 图像中心、四边和四角；
- 近、中、远距离；
- 左倾、右倾、前倾、后倾；
- 约10°～40°的多方向旋转。

要求：

- 激光关闭；
- 自动曝光、自动增益关闭；
- 分辨率和ROI固定；
- 焦距、光圈、对焦固定；
- 使用无损PNG；
- 板面不得弯曲；
- 必须让角点进入图像边缘区域。

### 5.3 质量参考


|    RMS重投影误差 | 评价               |
| ---------------: | ------------------ |
|     ≤0.20 pixel | 很好               |
| 0.20～0.35 pixel | 良好               |
| 0.35～0.50 pixel | 基本可用           |
|     ＞0.50 pixel | 建议检查图像和姿态 |

还应使用未参与标定的图像验证去畸变后的直线和独立重投影误差。

## 6. 激光平面标定

### 6.1 目标

求激光平面在相机坐标系中的方程：

\[
aX_C+bY_C+cZ_C+d=0
\]

### 6.2 采集方法

每个标定板姿态拍两张：

```text
pose_01_off.png   # 激光关闭，检测ChArUco
pose_01_on.png    # 激光打开，提取激光线
```

相机和标定板保持不动，只切换激光。建议采集20～30组，覆盖实际工作距离和多种倾斜姿态。

### 6.3 当前标定板平面

用ChArUco角点和PnP求：

\[
\mathbf X_C=R_{CB}\mathbf X_B+t_{CB}
\]

标定板法向量：

\[
\mathbf n_B=R_{CB}
\begin{bmatrix}0\\0\\1\end{bmatrix}
\]

标定板平面：

\[
\mathbf n_B^T\mathbf X_C+d_B=0
\]

\[
d_B=-\mathbf n_B^Tt_{CB}
\]

### 6.4 条纹提取

推荐差分：

\[
I_{diff}=\max(I_{on}-I_{off},0)
\]

流程：

```text
差分
→ 高斯滤波
→ 阈值和连通域
→ Steger/高斯拟合/灰度重心
→ 亚像素条纹中心
```

避免大面积饱和和只取整数最大灰度像素。

### 6.5 条纹像素恢复三维点

去畸变后，像素对应归一化射线：

\[
\mathbf r=
\begin{bmatrix}x_n\\y_n\\1\end{bmatrix}
\]

射线与当前标定板平面求交：

\[
\lambda=-\frac{d_B}{\mathbf n_B^T\mathbf r}
\]

\[
\mathbf X_C=\lambda\mathbf r
\]

每个姿态得到一条三维激光线。汇总所有三维点，先RANSAC剔除离群点，再用SVD拟合最终激光平面。

建议平面拟合RMS尽量小于0.15 mm，但最终精度必须用独立台阶件验证。

## 7. 单帧三维轮廓重建

对实际激光条纹像素，先去畸变，再与最终激光平面求交：

\[
\mathbf X_C=
-\frac{d_L}{\mathbf n_L^T\mathbf r}\mathbf r
\]

一帧图像得到：

\[
{}^C\mathcal P_i=
\{{}^Cp_{i,1},{}^Cp_{i,2},\ldots,{}^Cp_{i,m}\}
\]

建议每个点保存：

```text
x, y, z, intensity, confidence
```

置信度可由条纹亮度、宽度、饱和度、拟合残差和时序连续性确定。

## 8. 静态精度验证

在连接机器人移动建图前完成：

1. **静态平面**：连续100帧，统计点到平面RMSE和重复性；
2. **标准台阶**：2、5、10、20 mm高度；
3. **V形槽**：宽度、深度、角度、根部间隙和中心；
4. **视场位置**：左、中、右以及近、中、远距离。

当前配置初期可把静态综合误差进入0.2～0.5 mm级作为合理目标，不应仅凭理论公式宣称低于0.1 mm。

## 9. 相机—机器人手眼标定

坐标系建议：

- \(B\)：机器人基坐标系；
- \(F\)：法兰坐标系；
- \(T\)：工具/TCP；
- \(C\)：相机坐标系；
- \(W\)：工件坐标系。

若相机外参相对于工具：

\[
{}^B\mathbf P=
{}^B T_T(t)\,
{}^T T_C\,
{}^C\mathbf P
\]

若相对于法兰：

\[
{}^B\mathbf P=
{}^B T_F(t)\,
{}^F T_C\,
{}^C\mathbf P
\]

眼在手上标定建议：

1. ChArUco板固定在工作台；
2. 机器人携带相机拍摄10～20个不同姿态；
3. 必须有充分旋转；
4. 同步记录机器人法兰/TCP位姿；
5. 求相机到法兰或工具的固定变换；
6. 用未参与标定的姿态验证。

重点确认：

- 手眼矩阵方向是否取反；
- 使用的是法兰还是ToolCoord3；
- 法奥姿态顺序为浮动ZYX；
- 角度单位是度还是弧度；
- 平移单位统一为毫米。

## 10. 多位置静态重合验证

机器人在多个姿态静止测量同一个固定平面或台阶，点云转换到机器人基坐标系后应基本重合。

若不重合，优先检查：

- 手眼矩阵方向；
- TCP选择；
- ZYX欧拉角转换；
- 相机光学坐标方向；
- 毫米/米混用；
- 外参是否重复应用；
- 相机与传感器支架是否松动。

\[

## 12. 多帧点云构建
中
第 \(i\) 帧：

\[
{}^B\mathcal P_i=
{}^B T_T(t_i)\,
{}^T T_C\,
{}^C\mathcal P_i
\]

转换到工件坐标系：

\[
{}^W\mathcal P_i=
({}^B T_W)^{-1}
{}^B\mathcal P_i
\]

完整点云：

\[
\mathcal M_W=
\bigcup_i{}^W\mathcal P_i
\]

建议后处理：

```text
异常条纹点剔除
→ ROI裁剪
→ 统计/半径离群点滤波
→ 体素降采样
→ 坡口区域分割
→ 中心线提取
```

第一版不建议逐帧ICP。后续可用机器人位姿作为先验，加母材平面、截面连续性和焊缝平滑约束做二次优化。

推荐架构：

```text
Ubuntu主控
├── 法奥SDK与8 ms位姿流
```

\[

\]

## 16. 电气与6-pin接口原则

具体线色、针脚、电压和Line功能必须以当前相机型号手册、原厂线缆标签和万用表通断结果为准。

推荐功能：


| 功能          | 建议接口                       |
| ------------- | ------------------------------ |
| ESP32触发相机 | Line0光耦输入                  |
| 相机曝光输出  | 优先高速Line2                  |
| 备用曝光反馈  | Line1                          |
| 激光TTL       | Strobe经隔离、使能和缓冲后输入 |

原则：

- ESP32为3.3 V逻辑；
- 相机I/O可能是光耦、开漏或工业电平；
- 激光TTL可能需要5 V；
- 机器人I/O通常为24 V；
- 禁止未经转换直接互接。

前期常亮阶段不接TTL。正式阶段可采用：

```text
ESP32 → MOSFET/NPN开集电极 → 相机Line0
相机Line2 → ISO7721/ADuM/6N137 → 74AHCT缓冲 → 激光TTL
```

激光建议硬件联锁：

\[
LASER\_TTL=CAM\_STROBE\land LASER\_ENABLE
\]

## 20. 300～1000 mm量程扩展与机械臂协同

### 20.1 量程定义与总体结论

本节中的深度统一指相机光学坐标系中的 `camera Z`，不是 `base_link` 高度、机器人末端位移或工件总高度。

当前正式激光平面配置记录的有效范围为：

\[
Z_C=484.408\sim557.135\,mm
\]

该范围不是重建公式的物理硬限制，而是现有激光平面标定样本中有效三维点的实际深度包络。程序将它作为禁止外推的安全边界：

- `HikCalibrationWindow.cpp` 从标定点的最小/最大 `camera Z` 自动生成有效范围；
- `HikConstantLaserScanWindow.cpp` 将该范围载入常亮扫描重建参数；
- `HikCalibrationCore.cpp` 拒绝范围外的射线—激光平面交点。

因此，**不能只把 `hik_laser_plane.yaml` 手工改成300～1000 mm**。这种修改只能解除软件拦截，不能证明外推几何正确，也不能保证远端精度。

根据当前正式内参和激光平面进行理论计算，300 mm和1000 mm对应的激光条纹仍位于1440像素画幅内，因此现有光机结构具备开展全量程实验的基础；真正的限制是远端精度、景深、激光线焦和标定覆盖。

### 20.2 当前几何的量程与精度估算

当前正式参数近似为：

```text
fx = 1759.379 px
fy = 1758.577 px
有效三角测量基线 Beff ≈ 106.97 mm
激光平面内倾角 ≈ 8.05°
激光平面与相机光轴交点 Z ≈ 755.7 mm
```

由当前平面外推得到的条纹位置和深度灵敏度如下。条纹位置只用于检查视场可行性，不能替代重新标定：

| 相机Z | 中心行预计条纹位置 | \(\lvert\partial Z/\partial u\rvert\) | 条纹中心误差0.1 px对应的理想Z误差 |
| ---: | ---: | ---: | ---: |
| 300 mm | `u≈327 px` | 0.48 mm/px | 0.05 mm |
| 500 mm | `u≈577 px` | 1.33 mm/px | 0.13 mm |
| 700 mm | `u≈684 px` | 2.60 mm/px | 0.26 mm |
| 1000 mm | `u≈765 px` | 5.32 mm/px | 0.53 mm |

近似关系为：

\[
\left|\frac{\partial Z}{\partial u}\right|
\approx\frac{Z^2}{f_xB_{eff}}
\]

因此，同样的条纹中心误差在1000 mm处造成的深度误差约为300 mm处的11倍。如果中心误差为0.2 px，则1000 mm端仅像素定位项就约为1.06 mm，尚未包含内参、激光平面、手眼标定和机器人位姿误差。

当前6 mm镜头的针孔视场近似为：

| 相机Z | 水平视场 | 垂直视场 | 物方采样量级 |
| ---: | ---: | ---: | ---: |
| 300 mm | 245.5 mm | 184.2 mm | 约0.17 mm/px |
| 500 mm | 409 mm | 307 mm | 约0.28 mm/px |
| 1000 mm | 818.5 mm | 614 mm | 约0.57 mm/px |

所以“300～1000 mm能够输出点云”和“300～1000 mm保持相同精度与细节分辨率”是两个不同目标。

### 20.3 推荐的粗到精双层扫描模式

本系统最推荐利用FR5主动改变观测位置，而不是让单个固定视角承担700 mm跨度的高精度测量：

```text
全局图像或宽量程粗扫描
→ 获得300～1000 mm范围内的粗表面、遮挡和反光置信度
→ 生成候选机械臂观测姿态
→ FR5将扫描头移动到局部最佳工作距离
→ 保持约450～600 mm相机Z进行精细线扫
→ 对缺失、高反光和高不确定度区域选择新姿态补扫
→ 多姿态点云融合
```

建议将两个模式明确区分：

1. **宽量程粗扫描模式**：覆盖300～1000 mm，允许远端较大的深度不确定度，用于环境探索、工件定位、遮挡判断和下一视点生成。
2. **机械臂近距精扫描模式**：FR5沿工件表面改变位置和姿态，将局部工作距离维持在约450～600 mm，同时改变入射/观察角避开镜面反射，用于最终高质量点云。

这种架构能够直接体现机械臂协同的重要性：机械臂不仅提供扫描运动，还负责主动调节工作距离、三角测量精度、遮挡关系和反光角度。

未知场景下不能仅依赖单目图像保证机器人运动安全。第一阶段应使用已知工作台边界、保守碰撞包围盒和低速候选姿态；后续可增加粗深度传感器或经过验证的粗点云作为安全约束。

### 20.4 光学与激光调整

全量程实验前应完成以下检查：

1. 最终确定一条主激光并关闭另一条。Mono8相机下两条激光同时常亮会造成中心线混选，不能共用一个激光平面重建。
2. 在300、400、500、650、800、1000 mm放置哑光刚性平板，检查激光线是否始终在画幅内。
3. 激光有效扇角需要覆盖相机约34.3°的垂直视场，工程上建议有效扇角至少保留到约38°～40°。
4. 在300和1000 mm分别测量条纹FWHM、峰值、背景、饱和比例和中心时间抖动。激光线焦通常比相机景深更容易成为远端瓶颈。
5. 可从 `f/8` 附近开始实测景深，但不能盲目缩小到 `f/16`；过小光圈会降低信号并因衍射加宽条纹。
6. 建立按距离分段的曝光/激光功率LUT。300 mm端重点防止饱和，1000 mm端重点保证信噪比；Mono8峰值建议控制在约180～230 DN，饱和行比例控制在1%～5%以下。
7. 保持低增益或0 dB增益，正式阶段使用TTL只在曝光期间点亮激光。
8. 安装与激光波长匹配的窄带滤光片。若使用450 nm和650 nm双波长，必须分时触发、分别标定、逐帧记录 `laser_id`，不能同时点亮。

如果重新对焦、更换镜头、改变焦距、滤光片、保护玻璃、分辨率、binning或ROI，应重新标定相机内参。如果改变相机和激光器相对位置，应重新标定激光平面。

### 20.5 300～1000 mm全量程标定更新后的最终实施路线

#### 20.5.1 标定板

当前正式配置仍使用7×5、22/16 mm、约154×110 mm的小板。按当前内参估算，该板在1000 mm正视时的ChArUco内角点凸包面积可能只有整幅图像的约1.4%，低于当前检测器2%的质量门槛，容易被判定为“板图像面积太小”。

建议使用更大的高平面度刚性ChArUco板。第3章规划的11×8、300×230 mm板可用于远端标定；近端允许只看到部分图案，但必须满足角点、Marker、边界距离和板面物理范围检查。实际打印板、GUI参数、正式内参YAML和激光平面YAML必须完全一致。

标定板建议使用哑光陶瓷、微晶玻璃或经计量的高平面度铝板，不能用会翘曲的纸板作为亚毫米验收基准。

#### 20.5.2 内参重新标定

若光圈、焦点或光学件发生任何调整，应重新采集内参：

- 建议采集50～60张，最终保留30～40张以上高质量图像；
- 覆盖近、中、远距离以及画面中心、四边和四角；
- 包含绕X/Y轴的正负倾角；
- 使用最终分辨率、ROI、滤光片、保护玻璃、焦点和光圈；更新后的最终实施路线
- 激光关闭，自动曝光和自动增益关闭。

#### 20.5.3 激光平面重新标定

建议训练距离分层为：

```text
300、400、500、650、800、1000 mm
```

每个深度采集4～6个不同位置及正负倾角的严格 `laser-off` / `laser-on` 配对，总计约24～36组。每一对内部必须保持相机、标定板、曝光、增益和光学状态不变。

条件允许时，实际训练覆盖可扩展到约280～1050 mm，为正式工作区间留边界余量。不要让某一个距离占据大多数样本，求解时应按深度段和姿态均衡采样。

另保留以下距离作为不参加拟合的独立验证：

```text
350、550、750、950 mm
```

重新求解并通过质量检查后，软件会把真实标定点的Z包络写入新的正式 `hik_laser_plane.yaml`；射线与激光平面的求交公式不需要为了量程扩展而修改。

如果宽量程数据的残差随深度或图像行呈现稳定的系统曲线，说明实际激光片不能再用单一理想平面充分描述。此时应评估分区平面、逆深度多项式或标定查找表，而不是继续放宽平面RMS阈值。

### 20.6 软件增强建议

现有程序能够读取新的有效深度范围并完成重建，但若要把300～1000 mm作为正式产品指标，建议增加以下约束：

1. 将“期望工作范围”“训练样本范围”和“独立验证通过范围”分开记录，禁止用训练点极值直接代表产品有效量程。
2. 将深度划分为300～400、400～550、550～700、700～850、850～1000 mm等区间，每个区间要求最少训练姿态和独立验证姿态。
3. `laserResultPassesQuality()` 当前只要求总深度跨度不小于30 mm或平均深度的6%；应增加300/1000 mm端点覆盖和分段质量门槛。
4. 为每个重建点计算与 \(\lvert\partial Z/\partial u\rvert\)、条纹中心置信度和标定残差相关的 `sigma_z`，在远端融合时降权或拒绝低质量点。
5. 在激光平面配置中增加 `laser_id`、`wavelength_nm`、激光器序列号和支架版本，防止450/650 nm或不同安装状态的标定文件混用。
6. 保存每个深度段的有效点率、条纹宽度、饱和率、中心时间标准差、绝对Z误差、平面RMS、P95和台阶误差。
7. 增加配置往返测试、300/1000 mm边界测试，以及“缺少远端验证时禁止提升为正式配置”的自动化测试。

### 20.7 分段验证与验收

建议在300、400、500、650、800、1000 mm分别执行：

1. 固定相机与刚性平板，连续采集至少100帧；
2. 统计有效条纹行比例、FWHM、峰值、饱和比例和中心时间标准差；
3. 使用已计量的刚性平板检查点到平面RMS和P95；
4. 使用2、5、10、20 mm已知台阶检查绝对深度偏差和边缘误差；
5. 使用直线位移台、量块、千分表或激光位移计比较 \(\Delta Z_{camera}\) 与 \(\Delta Z_{reference}\)；
6. 在拉丝不锈钢、镜面金属、黑色涂层和曲面工件上统计完整率、离群率及姿态覆盖率；
7. 检查近端和远端没有被有效深度边界裁切。

平板RMS只表示点云对平面的离散程度，不等于Z轴绝对精度。全量程验收必须同时报告重复性、绝对误差、平面质量、点云完整率和已知尺寸误差。

可先采用以下阶段性目标，最终门槛应根据任务要求和标准件结果确定：

| 深度区间 | 现有6 mm光路建议的初始绝对误差目标 |
| --- | ---: |
| 300～600 mm | ≤0.5 mm |
| 600～800 mm | ≤0.8 mm |
| 800～1000 mm | ≤1.0～1.5 mm |

现有手眼标定的 `base_board_translation_rms_mm≈0.873 mm`、P95约1.440 mm，已经可能成为多姿态全局点云亚毫米重合的主要瓶颈。局部相机坐标系精度通过后，还必须重新验证或提高机械臂位姿与手眼坐标链精度。

### 20.8 是否需要更换硬件

| 目标 | 推荐方案 |
| --- | --- |
| 300～1000 mm能够获得粗点云，1000 mm端允许约1～2 mm误差 | 保留现有6 mm镜头和约107 mm有效基线，完成全量程重标定和分段验证 |
| 机器人工作空间覆盖300～1000 mm，但最终需要较高精度 | 保留现有扫描头，FR5主动保持约450～600 mm局部工作距离 |
| 固定视角下1000 mm端要求≤0.5 mm | 评估8～12 mm镜头、约130～150 mm或更大的有效基线，或者近/远双量程扫描头 |
| 需要0.2～0.3 mm级细节 | 必须让FR5靠近扫描，或采用更长焦、更高分辨率与更大基线；不能只扩大配置范围 |

增加焦距和基线会缩小近端视场、增大遮挡、头部尺寸和碰撞风险。所有光机改型应先在CAD或Isaac Sim中检查300/1000 mm条纹包络、相机—激光共同视场、FR5可达性、遮挡和安全距离，再制作支架并重新完成内参、激光平面和手眼标定。

## 21. 最终推荐路线

```text
1. 明确300～1000 mm是单视角量程还是机器人可达测量包络，并确定各深度允许误差
2. 最终确定相机、镜头、滤光片、保护玻璃和单条主激光
3. 在300～1000 mm全量程验证视场、景深、激光线焦、扇角和曝光范围
4. 标定相机内参与畸变
5. 分层标定激光平面，并使用独立距离验证正式有效范围
6. 验证平面、已知台阶和V槽，分别报告重复性与绝对误差
7. 完成并提高相机—FR5手眼标定
8. 多位置静态重合验证
9. 宽量程粗扫描获得工件、遮挡和反光置信度
10. FR5保持约450～600 mm局部距离实施主动近距精扫描
11. 对高反光、遮挡和高不确定度区域变换姿态补扫
12. 图像与机器人位姿插值，并进行正反向扫描时延估计
13. RViz显示机器人、单帧轮廓、粗点云和融合点云
14. 加入ESP32-S3硬同步与激光TTL门控
15. 提高速度并做焊后扫描
16. 进入活弧后视和多层多道闭环
```

最关键的原则：

> 在增加ESP32、TTL和活弧干扰前，先证明相机几何、激光平面、手眼矩阵、机器人位姿和点云坐标链完全正确。
