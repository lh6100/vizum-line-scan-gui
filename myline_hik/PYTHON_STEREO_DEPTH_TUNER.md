# Python 双目深度调优工具

这个工具直接使用海康 MVS SDK 连接两台相机，不启动 ROS2，也不会连接或移动机械臂。
它固定使用已经批准的 `config/hik_stereo.yaml` 和两台相机各自的内参，只把相机曝光、
预处理和 SGBM 参数作为调优项。

## 启动

先退出 MVS、Qt 标定程序和 ROS2 相机节点，确保相机未被占用，然后运行：

```bash
cd /path/to/vizum-line-scan-gui/myline_hik
./run_stereo_depth_tuner.sh
```

在页面中点击“连接并启动”。页面显示：

- 左目原图：160 万相机 `DA8784601 / 192.168.7.45`；
- 右目原图：130 万相机 `DB0403208 / 192.168.1.46`；
- 极线对齐图：左图为绿色、右图为紫色，物体的同名边缘应处在同一条黄色水平线上；
- 深度图：近处为红色、远处为蓝色、无效区域为黑色。

## 建议调参顺序

1. 关闭 450 nm 和 650 nm 线激光，保持场景有稳定的散斑或自然纹理。
2. 分别调节左右曝光，使两幅图的亮度和对比度尽可能接近，然后点击“应用相机参数”。
3. 检查配对偏差是否小于设置的门槛，通常保留 `30 ms`。
4. 先保持默认深度参数，观察“有效深度百分比”。
5. 若两图亮度仍不均匀，可尝试 CLAHE。深度参数停止修改约 450 ms 后会自动应用，
   统计区会显示真正生效的范围、块大小、左右检查和 CLAHE 状态。
6. 再依次微调唯一性比例、块大小和散斑窗口，每次只改一个参数并记录有效率和边缘质量。

左右曝光可以不同，但差异过大会改变纹理外观并显著降低匹配率。应以“左右亮度接近且有效深度率高”
为准，而不是单纯把图像调得更亮。

“保存调优配置”只保存到独立 YAML，不会覆盖正式双目标定文件。已有 YAML 中的
`multi_band` 三段深度配置会在再次保存时保留，供 ROS2 深度节点读取；调优页面本身仍用
当前界面中的单段范围做快速验证。“保存当前帧”会保存左右原图、极线图、深度预览、毫米
深度矩阵和有效掩膜。

## 诊断命令

只检查标定和深度几何：

```bash
./run_stereo_depth_tuner.sh --self-test
```

只枚举相机：

```bash
./run_stereo_depth_tuner.sh --list-cameras
```
