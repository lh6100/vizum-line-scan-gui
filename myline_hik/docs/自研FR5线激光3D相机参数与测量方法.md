## 1. 文档目的

本文建立当前自研系统的参数台账，并将每个参数标记为：

- **硬件标称**：来自设备型号或当前设置；
- **标定结果**：由内参、激光面或手眼求解得到；
- **理论估算**：由几何公式计算，只代表采样和敏感度；
- **软件实测**：由日志、队列和同步统计得到；
- **整机实测**：由标准件或工件测量得到；
- **待测**：目前没有可信结果，并给出测量方法。

必须避免以下错误：

- 把像素间距称为精度；
- 把内参重投影 RMS 称为三维精度；
- 把激光平面拟合残差称为绝对 Z 精度；
- 把单次人工选点称为整机验收；
- 把文件放入 `config` 等同于标定数据链已经正式通过。

## 2. 系统组成与测量链

```text
Hikrobot Mono8 图像
  -> 激光中心亚像素提取
  -> 相机内参去畸变
  -> 相机射线与激光平面求交
  -> 相机坐标三维轮廓

相机设备时间戳
  -> CLOCK_MONOTONIC_RAW
  -> 曝光中点
  -> FR5前后状态包
  -> XYZ线性插值 + Quaternion SLERP

相机轮廓
  -> T_base_flange × T_flange_camera
  -> base_link单帧轮廓
  -> 多帧连续点云
```

因此最终点云误差至少包含：

```text
相机成像
+ 激光中心
+ 内参
+ 激光平面
+ 手眼
+ FR5位姿
+ 时间同步
+ 机械刚度
+ 表面反射
+ 点云测量方法
```

## 8. 可以由现有参数直接计算的指标

本节全部属于理论估算，不是验收精度。

### 8.1 相机角视场

忽略畸变并使用完整1440×1080图像：

```text
FOV_X ≈ 2·atan(1440/(2·fx)) = 44.21°
FOV_Y ≈ 2·atan(1080/(2·fy)) = 33.89°
```

### 8.2 理论视场和横向像素间距

```text
视场宽 ≈ Z × 1440 / fx
视场高 ≈ Z × 1080 / fy
横向像素间距 ≈ Z / f
```

| 相机Z | 理论完整图像视场 | 横向像素间距 |
| ---: | ---: | ---: |
| 300 mm | 243.7×182.8 mm | 0.169 mm/px |
| 400 mm | 324.9×243.7 mm | 0.226 mm/px |
| 500 mm | 406.1×304.7 mm | 0.282 mm/px |
| 700 mm | 568.6×426.6 mm | 0.395 mm/px |
| 800 mm | 649.8×487.5 mm | 0.451 mm/px |
| 1000 mm | 812.3×609.4 mm | 0.564 mm/px |

这是相机图像的理论视场。实际有效激光线长度还受激光扇角、亮度、遮挡、
标定深度和条纹质量门槛限制，必须实测。

### 8.3 线激光三角测量公式

去畸变归一化射线：

```text
r = [xu, yu, 1]
```

与激光平面求交：

```text
Z = -d / (nx·xu + ny·yu + nz)
Pcamera = Z·r
```

当前激光面与相机光轴的几何夹角量级约`13.27°`。夹角较小会放大远距离
中心像素误差。

### 8.4 激光中心像素误差对Z的敏感度

当前平面主要沿图像V方向决定深度。在图像中央附近，忽略畸变：

```text
|dZ/dv| ≈ |ny|·Z² / (fy·|d|)
```

| 相机Z | 1 px中心误差对应Z变化 | 0.1 px对应Z变化 |
| ---: | ---: | ---: |
| 300 mm | 0.482 mm | 0.048 mm |
| 400 mm | 0.857 mm | 0.086 mm |
| 500 mm | 1.339 mm | 0.134 mm |
| 700 mm | 2.625 mm | 0.263 mm |
| 800 mm | 3.429 mm | 0.343 mm |
| 1000 mm | 5.358 mm | 0.536 mm |

因此“亚像素中心”不是足够的精度描述，必须实际测量中心重复性是
`0.02 px、0.1 px`还是更差。

### 8.5 激光面残差折算的内部Z量级

将当前平面内点RMS/P95沿相机射线折算：

```text
Z方向量级 ≈ 平面法向残差 × Z / |d|
```

| 相机Z | RMS折算 | P95折算 |
| ---: | ---: | ---: |
| 300 mm | 0.321 mm | 0.654 mm |
| 500 mm | 0.535 mm | 1.089 mm |
| 800 mm | 0.856 mm | 1.743 mm |
| 1000 mm | 1.070 mm | 2.179 mm |

这反映参与标定样本的内部一致性量级，不是独立标准件绝对精度，也不能与厂家
Z精度直接等价。

### 8.6 扫描方向线间距

```text
扫描方向线间距 = 机器人线速度 / 相机帧率
```

| 速度 | 60 fps理论线间距 |
| ---: | ---: |
| 10 mm/s | 0.1667 mm |
| 20 mm/s | 0.3333 mm |
| 30 mm/s | 0.5000 mm |
| 40 mm/s | 0.6667 mm |
| 50 mm/s | 0.8333 mm |

线间距描述采样密度，不表示该方向的测量精度。

### 8.7 曝光期间运动

```text
曝光运动量 = 速度 × 0.001825 s
```

| 速度 | 曝光运动量 |
| ---: | ---: |
| 10 mm/s | 0.0183 mm |
| 20 mm/s | 0.0365 mm |
| 30 mm/s | 0.0548 mm |
| 40 mm/s | 0.0730 mm |
| 50 mm/s | 0.0913 mm |

### 8.8 FR5状态样本间运动

按实际12 ms反馈周期：

| 速度 | 相邻FR5样本运动量 |
| ---: | ---: |
| 10 mm/s | 0.12 mm |
| 30 mm/s | 0.36 mm |
| 50 mm/s | 0.60 mm |

恒速和常加速度运动可由曝光中点插值补偿；该表不是插值后的剩余误差。

### 8.9 原始图像带宽

```text
1440 × 1080 × 60 = 93,312,000 byte/s
≈ 93.3 MB/s
≈ 746.5 Mbit/s
```

该值不包含GigE Vision、UDP、IP和以太网开销。

若每帧横向激光线覆盖1440列，最大名义轮廓采样吞吐约：

```text
1440 × 60 = 86,400 点/s
```

实际点数由可见线长和质量过滤决定。

## 12. 有效视场和横向采样测量方法

### 12.1 目的

测量真实可用激光线长度、有效点密度和视场边缘，不使用理论完整图像视场代替。

### 12.2 设备

- 带可溯源刻度、圆点阵列或棋盘格的哑光平板；
- 高精度距离基准；
- 刚性相机支架。

### 12.3 步骤

1. 将平板放在300、400、500、700、800、1000 mm。
2. 调整平板使激光线覆盖尽可能大范围。
3. 每个深度采集至少30帧。
4. 按正式质量门槛提取有效三维点。
5. 统计有效U/V边界和相机坐标X/Y范围。
6. 统计孔洞、断线和无效点比例。
7. 分别在视场中心和边缘放置已知尺寸特征。
8. 比较理论像素间距和实际可分辨特征。

### 12.4 输出

```text
camera_z_mm
valid_u_min, valid_u_max
valid_v_min, valid_v_max
valid_x_span_mm, valid_y_span_mm
valid_point_count
valid_ratio_percent
nominal_pitch_mm
smallest_resolved_feature_mm
```

## 13. 激光中心像素重复性测量方法

该测试隔离相机和激光中心算法，不引入机器人运动。

1. 相机、激光和哑光平板完全固定。
2. 在300、500、800、1000 mm分别采集至少500帧。
3. 保存未经压缩的原始Mono8图像。
4. 对每一列记录激光中心V坐标、峰值、半高宽和置信度。
5. 计算每列中心的标准差、P95和峰峰值。
6. 分别统计正常条纹、接近饱和条纹和高反光条纹。
7. 将像素标准差通过`dZ/dv`换算为理论Z噪声。

输出：

```text
center_stddev_px
center_p95_px
center_peak_to_peak_px
width_mean_px
width_p95_px
saturation_ratio
estimated_z_stddev_mm
```

这是判断系统能否达到`0.05 px`或`0.1 px`中心稳定性的关键实验。

## 14. Z向单点重复精度测量方法

### 14.1 传感头静态重复性

1. FR5保持静止，或将扫描头固定到独立刚性平台。
2. 使用高平面度哑光平板。
3. 在300、500、800、1000 mm各采集至少500帧。
4. 对固定U位置或小ROI计算每帧Z。
5. 输出均值、标准差、3σ、P95和峰峰值。
6. 在视场中心、边缘和不同入射角重复。

公式：

```text
sZ = sqrt(Σ(Zi − Z平均)²/(N−1))
```

### 14.2 整机重复性

1. 使用相同标准器和相同机器人路径。
2. 每次回到安全起点后重新扫描。
3. 正向5次、反向5次。
4. 不使用ICP，直接在base_link比较拟合几何。
5. 区分同帧轮廓重复性和多帧拼接重复性。

## 15. Z轴绝对精度测量方法

### 15.1 参考设备

优先使用：

- 激光干涉仪；
- 高精度直线模组；
- 坐标测量机；
- 带证书的阶梯高度标准。

不能直接把FR5绝对位置当作更高精度真值。

### 15.2 步骤

1. 使用独立参考建立相机光学Z方向的真实距离。
2. 在300、400、500、700、800、1000 mm放置哑光平板。
3. 每个位置采集至少30帧。
4. 对重建点拟合平面。
5. 计算测量平面位置与参考位置之差。
6. 在激光线不同U位置重复。
7. 改变平板正负倾角，检查三角测量角度影响。
8. 报告中心、边缘、近端和远端误差。

输出：

```text
reference_z_mm
measured_z_mean_mm
z_error_mm
z_error_rms_mm
z_error_p95_mm
z_error_max_mm
u_position
board_tilt_deg
temperature_c
```

## 16. 平面度和台阶高度测量方法

### 16.1 平面度

1. 使用有证书的哑光高平面度标准平板。
2. 分别静态扫描和连续扫描。
3. 在近、中、远深度和多个机器人姿态重复。
4. 拟合平面并计算点到面RMS、P95和最大值。
5. 生成误差随U、帧号和机器人位置的热力图。

### 16.2 台阶高度

1. 使用有证书的量块组合或阶梯高度标准。
2. 分别拟合上下两个平面。
3. 沿共同法向计算平面间距。
4. 不使用两个孤立点。
5. 测试不同高度、不同深度和正反扫描。

## 17. 长度测量精度

### 17.1 标准器

优先使用：

- 双球杆或球间距标准；
- 50/100/150 mm哑光长度标准；
- 两个平行基准面组成的量块/工装。

游标卡尺可用于工程检查，但不应作为最终可溯源标准。

### 17.2 方法

1. 分割两个标准球或两个基准面。
2. 拟合球心、平面或直线。
3. 计算几何中心/基准面之间距离。
4. 在X、Y、Z和对角方向放置标准器。
5. 在300、500、800、1000 mm重复。
6. 每个条件正向和反向各5次。
7. 使用多个真值拟合：

```text
L测量 = a·L真值 + b
```

其中：

- `a`表示比例误差；
- `b`表示固定偏差；
- 残差表示非线性、方向和随机误差。

只有当`a`跨深度和方向稳定时，才能考虑局部几何修正。不能对base_link全部
坐标直接做全局比例缩放。

## 18. 手眼精度验证方法

1. 使用不参与手眼求解的固定ChArUco板或标准球。
2. 选择至少6个独立机器人姿态。
3. 每个姿态重建标准器到base_link。
4. 比较不同姿态下拟合板面、球心或边缘是否重合。
5. 分别统计平移和旋转残差。
6. 增加第二旋转轴正负变化，避免只绕一个轴。
7. 用500和1000 mm杠杆距离检查角误差放大。

量级关系：

```text
位置误差 ≈ 杠杆距离 × 旋转误差(rad)
```

例如`0.1°`在500 mm处约为`0.87 mm`。

## 19. 固定时间偏差测量方法

1. 使用边缘清晰、哑光的台阶或球形标准器。
2. 以相同速度做正向和反向扫描。
3. 不使用ICP。
4. 拟合正反点云中特征位置。
5. 若正反特征间位置差为`Δx`、扫描速度为`v`，固定时间偏差量级为：

```text
|Δt| ≈ |Δx|/(2v)
```

6. 在10、30、50 mm/s至少三个速度验证。
7. 正确时间偏差应使空间错位随速度成比例，并在写入配置后显著减小。
8. 最终使用相机ExposureActive和示波器确认时间戳事件语义。

## 22. 温漂与长时间稳定性

2. 在5、15、30、60、120分钟重复静态平板测量。

   - FrameID缺口；
   - FR5 SDK序号缺口；

   - 内存增长；
   - 写盘速度；
   - 时钟拟合残差；

## 27. 最终结论

当前已经能够可靠给出的参数包括：

- 相机分辨率、内参和畸变；
- 激光平面及其拟合统计；
- 手眼变换及训练一致性；
- 相机60 fps和FR5约83.33 Hz；
- 理论视场、横向采样、扫描线间距和曝光运动量；
- 激光中心像素误差对Z的理论敏感度；
- 一次100 mm卡尺测量误差。

当前仍不能作为产品规格保证的参数包括：

- Z向单点重复精度；
- Z轴绝对精度；
- XY真实空间分辨率；
- 平面度和台阶高度精度；
- 100 mm长度保证精度；
- VDI/VDE整机测量精度；
- 高反光错误率；
- 跨深度、跨方向和跨日稳定性。

这些参数不能继续由标定RMS推断，必须按本文方法使用可溯源标准器实测。完成
静态传感头、手眼和动态整机三级验证后，才能形成与商业3D相机参数表可比较的
正式规格。
