## 2. 必须先区分的术语

### 2.1 分辨率

`1920×1216`表示相机或算法输出网格的名义采样数量。它不直接表示：

- 一个像素对应多少毫米；
- 能分辨的最小几何特征；
- 单点三维噪声；
- 长度、平面度或深度的绝对测量精度。

### 2.2 横向采样间距

横向名义采样间距可以由视场除以像素数估算：

```text
pX ≈ FOV_X / N_X
pY ≈ FOV_Y / N_Y
```

它描述理想情况下相邻输出采样点的物理间隔，不包含镜头模糊、双目匹配窗口、
插值、滤波和无效点。

### 2.3 Z 轴精度

通常描述测量深度相对于可溯源真实位置的系统偏差，例如：

```text
EZ = Z测量 − Z参考
```

它可能被厂家报告为最大绝对值、均值、RMS、P95 或若干倍标准差。没有脚注时
不能确定截图中的 `0.256/0.335/0.512 mm` 属于哪一种。

### 2.4 Z 向单点重复精度

描述设备和被测物都不动时，同一位置多次测量的离散程度。常见统计量包括：

```text
标准差：
sZ = sqrt(Σ(Zi − Z平均)² / (N−1))

峰峰值：
RZ = max(Zi) − min(Zi)
```

重复性可以很好但绝对值仍然有偏差，因此不能用重复精度代替 Z 轴精度。

### 2.5 VDI/VDE 测量精度

VDI/VDE 2634 Part 2 面向面扫描光学 3D 测量系统，使用长度标准和标准器进行
验收与复验，核心质量指标包括探测误差、球间距误差和平面度测量误差。
标准强调使用接近普通工件测量方式的标准器覆盖测量体积。

官方资料：

- [VDI/VDE 2634 Part 2 官方概览](https://www.vdi.de/fileadmin/pages/vdi_de/redakteure/richtlinien/inhaltsverzeichnisse/1907673.pdf)
- [NIST：VDI/VDE 长度测试对双目标定系统误差的敏感性](https://www.nist.gov/publications/vdivde-2634-1-performance-evaluation-tests-and-systematic-errors-passive-stereo-vision)

截图把多个可能的 VDI/VDE 指标合并为一个“测量精度”，必须取得厂家脚注或
检测报告，才能确认它是球间距最大误差、平面度误差、综合最大值还是典型值。

## 3. 可以由现有参数直接计算的结果

### 3.1 轴向像素映射假设

以下计算假设：

```text
短视场 X 对应 1216 像素
长视场 Y 对应 1920 像素
```

这是根据视场长宽关系作出的合理映射，但截图没有明确说明。若实际轴向相反，
每个轴的数值应交换；按面积计算的平均点间距不受该假设影响。

### 3.2 名义横向采样间距

| 工作距离 | X采样间距 | Y采样间距 | 面积等效平均间距 |
| ---: | ---: | ---: | ---: |
| 300 mm | 0.207 mm/px | 0.261 mm/px | 0.233 mm |
| 500 mm | 0.362 mm/px | 0.388 mm/px | 0.374 mm |
| 800 mm | 0.595 mm/px | 0.618 mm/px | 0.607 mm |

面积等效平均间距的计算为：

```text
p平均 = sqrt(FOV_X × FOV_Y / (1920 × 1216))
```

### 3.3 名义点密度

单次完整输出的名义采样数：

```text
1920 × 1216 = 2,334,720 点
```

| 工作距离 | 视场面积 | 名义点密度 |
| ---: | ---: | ---: |
| 300 mm | 126,504 mm² | 18.45 点/mm² |
| 500 mm | 327,360 mm² | 7.13 点/mm² |
| 800 mm | 859,388 mm² | 2.72 点/mm² |

实际有效点数会受遮挡、反光、暗表面、匹配置信度、边缘裁剪和滤波影响。

### 3.4 近似角视场

按简单针孔模型：

```text
视场角 ≈ 2 × atan(FOV / (2 × 工作距离))
```

| 工作距离 | X方向近似视场角 | Y方向近似视场角 |
| ---: | ---: | ---: |
| 300 mm | 45.6° | 79.8° |
| 500 mm | 47.5° | 73.3° |
| 800 mm | 48.7° | 73.1° |

300 mm 的 Y 方向结果与远距离差异较大，说明表中的“视场”可能是双目共同有效
测量体积边界，而不是单个镜头的简单光学视场。因此这些角度只作近似。

### 3.5 相对精度

| 工作距离 | Z轴精度/距离 | 单点重复精度/距离 | VDI/VDE数值/距离 |
| ---: | ---: | ---: | ---: |
| 300 mm | 0.0853% | 0.0057% | 0.0917% |
| 500 mm | 0.0670% | 0.0062% | 0.0716% |
| 800 mm | 0.0640% | 0.0116% | 0.0843% |

这些比例便于观察趋势，但不代表设备具有固定百分比误差。

### 3.6 吞吐量估计

若“3000线/s”的每条线包含1920个有效采样，则理论原始采样吞吐为：

```text
3000 × 1920 = 5,760,000 点/s
```

该估计不包含无效点、编码、传输、双目匹配和三维计算开销，也不能把
`3000线/s`直接解释为3000个完整三维帧。

典型采集时间 `0.5–2 s`对应约：

```text
0.5–2 次完整采集/s
```

应向厂家确认采集时间是否包含投影序列、曝光、传输、三维重建和滤波。

## 4. 不能由截图参数直接计算的结果

以下指标必须通过实验或取得厂家内部模型：

- Z轴绝对精度；
- Z向单点重复精度；
- VDI/VDE长度、球和面测量误差；
- XY实际几何分辨率；
- 高反光、黑色和透明物体的有效率；
- 温漂和长期稳定性；
- 视场边缘精度；
- 不同曝光、HDR和滤波模式下的精度；
- 设备间一致性；
- 机械安装后的整机精度。

双目三角测量的基本关系为：

```text
Z = f × B / d
σZ ≈ Z² × σd / (f × B)
```

其中：

- `f`：标定后的像素焦距；
- `B`：双目基线；
- `d`：视差；
- `σd`：亚像素视差噪声。

截图没有提供 `f、B、σd`，所以不能从分辨率和视场反推出表中的 Z 精度。
即使取得这些参数，公式也只给随机噪声量级，不能包含标定偏差、镜头畸变残差、
温漂、目标反射和算法滤波。

## 5. 建议的参数测量条件

所有精度测试至少应记录：

| 项目 | 建议 |
| --- | --- |
| 预热 | 按厂家要求；若未知，至少30分钟 |
| 环境温度 | 建议20±1 ℃并记录实际值 |
| 振动 | 相机、标准器和平台刚性固定 |
| 标准器表面 | 漫反射哑光；另做高反光专项 |
| 环境光 | 固定并记录；避免阳光和频闪 |
| 自动功能 | 关闭自动曝光、自动增益和自动滤波切换 |
| 采集数量 | 重复性每位置至少100帧 |
| 工作距离 | 300、500、800 mm，必要时增加中间点 |
| 视场位置 | 中心、四角、四边，共至少9个区域 |
| 数据 | 保存原始深度、置信度、曝光和配置 |
| 标准器溯源 | 记录证书、编号、不确定度和有效期 |

测试报告必须说明是否使用：

- 空间平均；
- 时间平均；
- 中值滤波；
- 孔洞填充；
- 离群点删除；
- 多曝光/HDR；
- 降采样；
- 多帧融合。

未经说明的滤波会让重复性数字变好，却可能降低边缘真实性或掩盖系统偏差。

## 6. Z向单点重复精度测量方法

### 6.1 设备

- 高平面度哑光标准平板；
- 刚性光学平台；
- 温度计；
- 相机原始深度输出；
- 可选：高精度直线模组用于改变工作距离。

### 6.2 步骤

1. 相机预热并固定曝光、增益、HDR和滤波参数。
2. 将平板放置在300 mm，法向尽量对准相机。
3. 在视场中心选择固定小ROI，例如 `5×5` 或 `11×11` 像素。
4. 连续采集至少100帧，不移动相机和平板。
5. 每帧记录ROI中位Z，避免单个坏点控制结果。
6. 计算均值、标准差、P95绝对偏差和峰峰值。
7. 在视场四角、四边重复。
8. 在500和800 mm重复全部测试。
9. 另做开机后0、30、60、120分钟的温漂测试。

### 6.3 输出

```text
distance_mm
roi_x, roi_y
sample_count
mean_z_mm
stddev_z_mm
three_sigma_mm
p95_abs_deviation_mm
peak_to_peak_mm
valid_ratio_percent
temperature_c
```

不能只写“重复精度0.017 mm”，必须明确该值对应哪种统计量。

## 7. Z轴绝对精度测量方法

### 7.1 设备

- 可溯源激光干涉仪、精密直线模组或坐标测量机；
- 哑光高平面度平板；
- 标准量块或阶梯高度标准；
- 刚性安装架。

不建议使用普通机器人绝对位置作为Z精度真值，除非机器人位姿已经由更高精度
外部设备标定。

### 7.2 步骤

1. 建立可溯源参考零位。
2. 将平板放在300、500、800 mm及若干中间位置。
3. 每个位置连续采集至少30帧。
4. 对有效点拟合平面，不使用单点。
5. 计算测量平面位置与参考位置的差。
6. 将平板移动到视场中心、边缘和角落重复。
7. 改变平板倾角，检查入射角对误差的影响。
8. 正向和反向移动到同一位置，检查模组回差。
9. 分别报告原始结果和任何滤波后的结果。

### 7.3 建议指标

```text
平均Z偏差
最大绝对Z偏差
Z偏差RMS
Z偏差P95
视场中心与边缘差异
正反移动回差
温漂
参考标准不确定度
```

## 8. VDI/VDE测量精度验证方法

正式验收应购买并按照适用版本的标准原文执行；本文只给工程准备框架，不替代
标准规定的测试数量、位置和判定方法。

### 8.1 平面度测量

1. 使用有证书的高平面度哑光平板。
2. 在测量体积多个位置和倾角采集。
3. 拟合参考平面。
4. 统计点到拟合平面的偏差范围、RMS和P95。
5. 分别报告中心与边缘区域。

### 8.2 标准球探测误差

1. 使用直径和形状有证书的哑光标准球。
2. 在测量体积不同位置采集完整可见球面。
3. 拟合球心和直径。
4. 计算径向残差范围和测得直径相对证书值的偏差。
5. 避免只测球面很小的一块区域。

### 8.3 球间距或长度误差

1. 使用有证书的双球杆、球间距标准或长度标准。
2. 让标准器以不同方向和位置覆盖测量体积。
3. 分别拟合两个球心或两个基准几何面。
4. 计算测得距离与证书距离之差。
5. 报告最大正误差、最大负误差、最大绝对误差、RMS和测量不确定度。

### 8.4 不能省略的信息

- 使用的是VDI/VDE 2634哪一部分和哪个版本；
- 标准器类型、尺寸、证书和不确定度；
- 测量位置和方向；
- 是否取最大值、RMS、P95或若干倍标准差；
- 是否使用平均、滤波、HDR或多帧融合；
- 合格判定值是制造商最大允许误差还是样机典型值。

## 9. 视场与XY采样验证方法

1. 在300、500、800 mm放置带有可溯源刻度或圆点阵列的平板。
2. 确定点云中连续、有效且满足质量门槛的边界。
3. 计算有效边界的X/Y跨度，而不是使用图像黑边。
4. 统计有效点数和孔洞比例。
5. 计算：

```text
有效X采样间距 = 有效X跨度 / 有效列数
有效Y采样间距 = 有效Y跨度 / 有效行数
有效点密度 = 有效点数 / 有效面积
```

6. 在哑光白、灰、黑以及高反光表面分别重复。

## 10. 典型采集时间和线扫速率验证

### 10.1 典型采集时间

分别测量：

```text
触发到曝光开始
投影/编码序列时间
曝光总时间
传输时间
三维计算时间
滤波时间
触发到完整点云可用总时间
```

至少记录平均值、P95、P99和最大值。不能只用平均值解释实时性。

### 10.2 最大线扫速率

在3000线/s下持续运行至少30分钟，记录：

- 实际线频；
- 输入/输出线数；
- 丢线和重复线；
- 曝光时间；
- 输出点数；
- 数据带宽；
- CPU/GPU占用；
- 温度；
- 时间戳连续性。

如果3000线/s需要缩小ROI、降低曝光或关闭部分算法，必须在规格旁明确注明。

## 11. 高反光和复杂表面专项

精度表通常来自受控哑光标准器，不能直接代表金属、黑色、透明或半透明工件。

建议至少测试：

| 表面 | 关注指标 |
| --- | --- |
| 哑光白 | 基准精度与重复性 |
| 哑光灰 | 灰度变化影响 |
| 哑光黑 | 有效率和噪声 |
| 拉丝金属 | 方向性反射 |
| 镜面金属 | 饱和、多径和错误点 |
| 半透明塑料 | 次表面散射和深度偏移 |

每种材料报告：

```text
有效点率
错误点率
Z偏差
重复性
孔洞比例
置信度分布
曝光/HDR配置
```

## 15. 结论

由截图能够可靠计算的是：

- 名义横向采样间距；
- 名义点密度；
- 近似角视场；
- 相对误差比例；
- 理论数据吞吐。

无法仅由截图计算的是：

- Z轴绝对精度；
- Z向单点重复精度；
- VDI/VDE整机测量精度；
- 高反光和复杂表面性能；
- 实际生产环境下的测量不确定度。

这些指标必须使用可溯源标准器、明确的统计定义和完整测试条件实测。购买或选型
