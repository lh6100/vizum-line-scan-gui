# scanner_650 全局粗扫与局部补扫

本文说明 `HikConstantLaserScan` 中 scanner_650 自适应扫描 v1 的配置、操作顺序、数据契约和安全边界。当前版本只服务于已完成独立标定的 650 nm、160 万相机、6 mm 镜头设备组；scanner_450 不参与规划。

## 1. v1 的工作范围

当前实现包含：

1. 从已示教的第一条扫描带生成固定、交替方向的全局蛇形路径；
2. 每条测量带使用 lead-in、有效测量段和 lead-out，带间插入转场段；
3. 对完整物理路径从 FR5 当前位姿开始采样，逐点执行链式 IK、关节软限位余量和数值 Jacobian 奇异性检查；
4. 全局粗扫仅启动一次相机连续流，只有位于有效测量段空间门控内的帧可以进入正式重建；
5. 在 `base_link` 中建立体素覆盖/质量地图，分别保留正式点、质量候选点和被拒绝点的证据；
6. 聚类需要补扫的体素，生成有限的局部候选库，并同时输出 greedy NBS 和 2～3 段 beam search 结果；
7. 保存规划估计时间、逐段 FR5 校验结果和真实运动完成时间。

v1 不包含在线连续重规划、强化学习、scanner_450 局部精扫，也不自动执行局部 NBS。

## 2. 独立配置

配置文件为 [`config/devices/scanner_650/adaptive_scan_650.yaml`](../config/devices/scanner_650/adaptive_scan_650.yaml)。程序通过 scanner_650 设备档案定位并严格读取它；缺字段、越界值或不安全的 safety 开关会禁用四个自适应按钮。

主要配置组：

| 配置组 | 作用 |
| --- | --- |
| `global` | 带间偏移、扫描带数、lead-in/out、MoveC 半径/融合参数和总路径上限 |
| `quality_map` | 体素尺寸、最低平均置信度、拒绝比例和最少正式观测数 |
| `roi` | 缺陷体素聚类、外扩、最大范围和最多参与候选生成的 ROI 数 |
| `candidate_library` | yaw/pitch、工作距离、速度、曝光、反向扫描和候选总数上限 |
| `search` | beam 时域、宽度、FR5 评估短名单和单 ROI 保留数 |
| `fr5` | 笛卡尔/角度采样间隔、关节余量、奇异值阈值和采样上限 |
| `safety` | 当前安全能力声明 |

界面可临时修改蛇形几何、体素尺寸和 beam 参数。修改蛇形几何后，已有 FR5 评估立即失效，必须重新生成和评估。

`global.enable_arc_transitions` 默认启用带间半圆。半径由相邻测量带物理端点间距的一半确定，并受 `minimum_arc_radius_mm`、`maximum_arc_radius_mm` 和 `maximum_arc_tangent_error_deg` 约束；`transition_blend_radius_mm` 是提交给控制器的正 `blendR` 上限。最大圆弧半径只是几何包络，不代表该空间没有工件、夹具或线缆碰撞。

`safety.collision_model_validated` 和 `safety.local_adaptive_execution_enabled` 当前必须保持 `0`。不能通过编辑 YAML 绕过尚未实现的碰撞验证和局部执行禁用。

## 3. 全局粗扫操作顺序

开始前应完成相机、TTL、FR5 连接，确认 scanner_650 正式内参、激光平面和手眼标定校验通过，并确认物理急停有效。

1. 在“连续建图模式”中选择“自适应质量建图”。执行固定全局粗扫时程序也会自动选择该模式；普通快速建图只保存 raw/voxel，不能直接生成局部 NBS。
2. 示教第一条扫描带的起点和终点。它们只定义有效测量段，程序按方向外延 lead-in 和 lead-out。
3. 设置带间偏移 X/Y/Z、带数、扫描速度、转场速度和 lead-in/out。
4. 点击“1. 生成全局蛇形 dry-run”，检查每个测量段、转场段、总长度和预计时间。
5. 点击“2. FR5 评估全局路径”。程序读取实际当前法兰位姿，从该位姿到第一段起点，并对所有后续段逐点链式检查。
6. 只有全部段的 IK、关节余量和奇异性通过后，固定全局粗扫才可能执行。
7. 取消总界面的 dry-run，勾选安全确认，再点击“3. 执行固定全局粗扫”。
8. 程序在发送运动前再次读取实际法兰位姿。相对评估起点偏移超过 `0.20 mm` 或 `0.10°` 时，评估作废，必须重新执行第 5 步。
9. 阅读碰撞未知警告并人工确认完整固定路径后才会开始运动。

相机在第一段 lead-in 起点只启动一次，在全部段完成或异常停止后关闭。每条直线测量带都配置独立的空间门控；只有落在该带有效起止点之间的同步位姿可以发布点云。lead-in/out、带间 MoveC/回退 MoveL 以及无法匹配任何测量带的帧统一标记为 `OUTSIDE_VALID_SCAN_SEGMENT`。

正常路径由直线测量 `MoveL` 和带中间点的半圆 `MoveC` 交替组成。FR5 后端沿真实直线/圆弧采样，逐点做链式 IK、关节余量和数值 Jacobian 奇异性检查；全部通过后，先求解整条轨迹，再连续提交所有 `MoveL/MoveC`。非末段使用正 `blendR`，最后一段使用 `blendR=0`，避免软件逐段等待造成的段端停顿。

任何圆弧半径、切向几何、IK、关节余量或奇异性检查失败时，软件不会混合执行剩余圆弧：所有带间转场统一改成 `blendR=0` 的停稳直线，并从实际当前位姿重新评估整条路径。回退模式逐段等待到位；转场门控始终关闭。碰撞模型仍为 `UNKNOWN`，因此圆弧或直线都必须由操作者现场确认空间安全。

## 4. 质量地图与局部 NBS

自适应质量粗扫保存成功后，程序在内存保留三类证据。质量地图、ROI 和候选不在
扫描结束回调中阻塞生成，而是在用户点击第 4 步局部 NBS 按钮时按需转换为
`base_link` 体素证据：

| 输入 | 用途 |
| --- | --- |
| `formal` | 正式可发布几何、覆盖次数和已观测视角 |
| `qualityAccepted` | shadow/quality 并行算法的候选证据，不替代正式几何 |
| `rejected` | 二维质量硬门控、多径、饱和、路径歧义、相邻帧支持或三维几何门控的拒绝证据 |

拒绝点不会参与 ROI 的正式几何 PCA。视角多样性使用正式点记录的真实相机原点；旧数据没有相机原点时才退回到候选姿态角差。

体素满足观测不足、低置信度、拒绝占优、多径、饱和、路径歧义、支持不足或几何无效等条件时进入补扫集合。相邻补扫体素在 3D 中聚类为 ROI。未提供 CAD/目标表面 mask 时，系统只能发现“已有观测附近的低质量或拒绝区域”，不能证明从未看到的整块区域已经覆盖。

点击“4. 质量地图 + 局部 greedy/beam”后：

1. 对每个 ROI 按有限 yaw、pitch、距离、速度、曝光和方向组合生成候选；
2. 使用正式标定参数验证视场和激光扫掠可观测性；
3. 先按信息增益与代价排序形成短名单；
4. 从 FR5 当前位姿评估每个首段以及候选之间的有序转移；
5. 输出单步 greedy NBS 和 2～3 段 beam search；beam 对已覆盖 ROI/体素去重，并计入换姿态、启停和运动时间。

由于当前没有工件遮挡模型，`occlusion=UNKNOWN`；由于没有经过验证的机器人、扫描头、线缆、夹具和工件碰撞场景，`collision=UNKNOWN`。任一 UNKNOWN 都使局部计划保持 dry-run，界面没有自动执行入口。

## 5. 安全状态

| 场景 | IK/关节/奇异性 | 碰撞 | 执行策略 |
| --- | --- | --- | --- |
| 固定全局粗扫 | 必须全部通过 | `UNKNOWN` | 仅允许操作者检查固定路径并二次确认后执行 |
| 局部 greedy/beam | 会真实调用 FR5 后端评估 | `UNKNOWN` | 只保存 dry-run，禁止自动运动 |
| 任意失败、超时或采集停止异常 | 视为失败 | 不放宽 | 请求停机、关光，保存已获得的审计数据 |

全局计划的 `safety_verified` 和 `executable` 在碰撞仍未知时保持 `false`。固定全局路径的人工确认是一个受控的 v1 例外，不表示软件已经完成全碰撞验证。

## 6. 输出和审计

全局扫描会话中保存：

- `continuous_raw.ply`、`continuous_voxel.ply`；
- 同步 CSV、原图和逐帧重建详情；
- `adaptive_scan_plan.json`。

选择“自适应质量建图”时，quality accepted/rejected 与邻帧支持分类在内存中提供给
局部 NBS，但当前不写 optical/filtered/rejected/quality_voxel 四份附加 PLY。选择
默认“普通快速建图”时，上述质量候选、V 槽时序验证、邻帧分类和 rejected 收集都
跳过。两种模式的 raw/voxel 默认使用二进制 PLY；扫描结束后的计算与写盘在后台
线程执行，执行区显示阶段进度。需要离线质量审计时使用原始 PNG 和逐帧重建 CSV
回放。

没有扫描会话时，dry-run 预览保存在 `data/scan/scanner_650/adaptive_plans/`。

`adaptive_scan_plan.json` 包含：

- 全局每段的测量起止、物理运动起止、`LINE/ARC`、圆弧中间点/半径、`blendR`、回退原因、速度、曝光和 lead-in/out；
- 每段 IK、碰撞、奇异性、最小关节余量、最小归一化奇异值、预计运动时间和实测运动时间；
- 每个质量体素的计数、光学统计、质量/拒绝位标志、严重度和真实观测视角；
- 自动聚类 ROI；
- 局部候选的姿态、可观测性、机器人评估以及 greedy/beam 结果。

预计时间来自规划前的梯形速度模型；实测时间来自控制器完成或停止确认时的单调时钟。两者分别保存，不互相覆盖。

## 7. 下一阶段

局部计划要开放真实执行，至少还需要：

1. 建立并现场验证 FR5、扫描头、线缆、夹具、工件和安全区碰撞模型；
2. 接入工件 CAD 或目标表面 mask，区分真正未覆盖区域与工作空间外区域；
3. 建立遮挡/可见性模型；
4. 对局部多段执行状态机做低速空载、假负载和实物分级验收；
5. scanner_450 独立标定完成后，再作为窄视场局部精扫设备接入同一质量地图。

上述条件满足后，再考虑短时域在线重规划；第一版无需强化学习。
